# AI-Powered Indian Urban Traffic Digital Twin

An AI-powered real-time traffic management and Digital Twin platform
designed for Indian urban traffic networks.

## Objectives

- Real-time CCTV-based traffic perception
- Indian vehicle detection and classification
- Multi-object vehicle tracking
- Lane and movement detection
- Real-time traffic-state estimation
- Traffic prediction
- SUMO Digital Twin
- AI-based traffic signal optimization
- Emergency green corridor
- Pedestrian and incident handling
- Multi-junction coordination
- Safety supervision and fail-safe operation
- FastAPI backend
- Streamlit monitoring dashboard
- Hardware-in-the-loop validation
